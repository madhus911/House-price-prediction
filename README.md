# House-price-prediction
House price prediction using Linear Regression and Random Forest

## Project Overview

This project predicts the house prices using machine learning

The Kaggle House prices dataset is used for training and evaluating the model

## Machine learning models

- Linear Regression
- Random Forest Regressor

## Best Model

Random Forest Regressor

### Performance

- MAE:$17,577
- RMSE:$28,983
- R2 score:0.8905
